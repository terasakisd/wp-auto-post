# 入稿さん — Manuscript to WordPress

ディレクション済みの原稿 (.md) を添付して送信するだけで、参考記事の「書き方」(タグ・クラスの使い方) を学習し、変換・本文照合・WordPressへの入稿まで自動で行うローカルアプリです。

**本文テキストは一切変更されません。** 原稿はテンプレートへ機械的に流し込まれ、入稿前に原稿と生成HTMLの全文照合が行われます。不一致が検出された場合は入稿を中止します。

## 起動方法

```bash
cd wp-auto-post
node server.js
```

ブラウザで http://127.0.0.1:3777 を開く。(Node.js 18以上。依存パッケージなし)

## 使い方

1. 右上の歯車から設定を入力 (サイトごとに保存されます)
   - サイト名 / サイトURL / ユーザー名 / アプリケーションパスワード
   - 参考記事のURL (同じサイトの公開済み記事。書き方の学習元)
   - AIに渡すメモ (任意。そのサイトの書き方の注意点を自由記述でAIに伝える)
   - Claude APIキー (任意) と AI変換モード
   - 投稿ステータス (既定: 下書き)
2. 原稿 (.md) をドロップまたは添付 → 解析・学習・変換・照合・入稿まで全自動
3. 完了後、編集リンクとプレビュー・生成HTMLを確認できます

## 書き方の学習と変換の仕組み

- 参考記事は **編集画面の生HTML (REST API `context=edit`)** を最優先で取得します (認証情報が参考記事と同じサイトの場合のみ使用)。クラシックエディタの「段落はタグなしの素の行」「インラインstyleの装飾」までそのまま学習します。取得できない場合は表示用HTML→ページHTMLの順にフォールバック。
- **AI変換モード**
  - 節約 (既定): AIは参考記事から書き方テンプレートだけを一度生成 (Haiku・サイトごと初回のみ)。テンプレートはキャッシュされ、2記事目からはAPI料金0円。
  - 高品質: AIは本文を {{トークン}} に置き換えた**骨組みだけ**を組み立て、サーバがトークンに原稿テキストを差し戻します (プレースホルダー方式)。**本文はAIを一切通りません。**
- どの経路でも、入稿前にタグを剥がした全文照合 (エンティティ・ゼロ幅文字も正規化) を行い、一字でも違えば入稿しません。

## 複数サイト

左上のメニューで入稿先サイトを切り替えられます。「＋ サイトを追加…」で何サイトでも登録可能。設定はサイトごとに保存されます。

## ディスクリプション

原稿冒頭の「■ディスクリプション」は、抜粋 (excerpt) に保存するとともに、サイトのSEOプラグインを**自動検出**してメタディスクリプション欄にも書き込みます。

- 対応: Yoast SEO / Rank Math / SEO SIMPLE PACK / Cocoon
- サイトがREST経由のmeta書き込みを受け付けない場合は抜粋のみに保存し、その旨を結果に表示します。確実にメタ欄へ入れたい場合は、テーマの functions.php 等で該当metaキーを `register_post_meta(..., ['show_in_rest' => true])` で登録してください。

## 原稿の対応書式

- `# タイトル` → 記事タイトル
- `| ■ディスクリプション … |` の表 → ディスクリプション
- `## \<h2\>見出し\</h2\>` / `### \<h3\>…\</h3\>` → h2 / h3 (マーカーは自動除去)
- `* 項目` → 箇条書き
- 複数列の表 → table (先頭行がヘッダー)
- `| *口コミ… 引用：[リンク](URL)* |` → 引用ブロック (blockquote + cite)
- その他の単一セル表 (立札例・電話番号など) → 強調ボックス

## セキュリティ

- サーバは 127.0.0.1 のみで待ち受け。外部からアクセスできません。
- 接続情報はブラウザのローカルストレージにのみ保存されます。
